# 🎬 Reelify - Short Video Platform

**Reelify** is a modern, web-based short video platform inspired by Instagram Reels and TikTok. Built with **HTML, CSS, and JavaScript**, it delivers an immersive and interactive video viewing experience with smooth performance.

---

## ✨ Key Features

*   **📱 Vertical Scrolling:** Seamless vertical navigation between reels using CSS Scroll Snap.
*   **❤️ Interactive Like System:** Engaging "Double-tap to like" feature with custom heart animations.
*   **⏯️ Smart Playback:** Uses `Intersection Observer` to automatically play videos when they enter the viewport and pause them when they leave, optimizing performance.
*   **🔇 Intuitive Controls:**
    *   **Click** to Toggle Mute/Unmute.
    *   **Press & Hold** to Pause the video (hides UI for a clean view).
*   **💬 Comments & Social:** Slide-up comment section, dynamic subscribe button, and share options.
*   **🎨 Modern UI/UX:** Sleek dark mode design, custom loading animations, and a fully responsive layout that looks great on both mobile and desktop.

---

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3 (Flexbox, Grid, CSS Variables), Vanilla JavaScript (ES6+)
*   **Icons:** Remix Icon Library
*   **Assets:** Cloudinary & Unsplash (for demo content)

---

## 🚀 How to Run

Follow these steps to run the project locally on your machine:

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    ```

2.  **Navigate to the project folder:**
    ```bash
    cd reels
    ```

3.  **Open the project:**
    Simply open the `index.html` file in any modern web browser (Google Chrome, Edge, Firefox, etc.).
